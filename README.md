# Трекер привычек

Веб-приложение для телефона: добавляйте привычки (отжимания, приседания, бег…),
задавайте план — «N раз в неделю» или по конкретным дням недели — и отмечайте
выполнение галочкой. Напоминания: событие в Google Calendar и/или будильник со звуком.

Логика приложения описана в [ALGORITHM.md](ALGORITHM.md).

## Возможности
- **Сегодня** — привычки на день, большая кнопка-галочка, прогресс недели, серия 🔥.
- **Неделя** — таблица Пн–Вс, отметки нажатием на ячейку, итог «сделано / план».
- **Календарь** — месяц по каждой привычке, статистика (за месяц, всего, текущая и лучшая серия).
- **Статистика** — неделя или месяц: ✅ выполнено, ⏳ осталось, ❌ пропущено, процент плана,
  таблица по привычкам и график за последние 8 недель.
- **Напоминания** — кнопка «Добавить в Google Calendar» (повторяющееся событие),
  файл `.ics` для любого календаря, будильник со звуком и вибрацией внутри приложения.
- **Настройки** (кнопка ⚙ вверху) — уведомления, проверка будильника, резервная копия в файл и восстановление.
- Работает без интернета, можно установить на экран «Домой».

## Запуск на телефоне через GitHub Pages
1. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)` → **Save**.
2. Через 1–2 минуты приложение будет доступно по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`.
3. Откройте адрес на телефоне и добавьте на экран «Домой»:
   - iPhone (Safari): «Поделиться» → «На экран „Домой“»;
   - Android (Chrome): ⋮ → «Добавить на главный экран».

## Важно про напоминания
- **Будильник** звонит, только пока приложение открыто (или свёрнуто, но браузер его ещё не выгрузил).
  Браузер разрешает звук после первого касания экрана — об этом напомнит жёлтая плашка.
- **Google Calendar** напоминает всегда, даже когда приложение закрыто.
  Время уведомления берётся из ваших настроек Google Calendar (по умолчанию — за 10 минут).
- Данные хранятся только в браузере телефона. Время от времени делайте резервную копию в «Настройках».

## Файлы
| Файл | Назначение |
|---|---|
| `index.html` | разметка экранов |
| `style.css` | оформление (светлая и тёмная тема) |
| `app.js` | вся логика: привычки, отметки, статистика, календарь, будильник |
| `sw.js` | офлайн-режим и уведомления |
| `manifest.webmanifest`, `icons/` | установка на экран «Домой» |
