# Алгоритм приложения «Трекер привычек»

Веб-приложение для браузера телефона. Работает без сервера и регистрации:
все данные хранятся в памяти браузера (localStorage) на этом телефоне.

---

## 1. Данные

### Привычка
| Поле | Описание |
|---|---|
| `id` | уникальный идентификатор |
| `name` | название («Отжимания») |
| `mode` | `weekly` — «N раз в неделю», в любые дни; `days` — по конкретным дням недели |
| `times` | план на неделю для режима `weekly` (1–7) |
| `days` | список дней недели для режима `days` (0 = Пн … 6 = Вс) |
| `reminder.time` | время напоминания `ЧЧ:ММ` (или пусто) |
| `reminder.alarm` | включён ли будильник со звуком |
| `createdAt` | дата создания |

### Отметки
`checks[idПривычки][ГГГГ-ММ-ДД] = true` — привычка выполнена в этот день.
Нет записи — не выполнена.

### Служебное
`fired[ГГГГ-ММ-ДД|idПривычки]` — будильник на этот день уже сработал (чтобы не звонил повторно).

---

## 2. Основные расчёты

Неделя начинается с понедельника.

**План на неделю**
- `weekly` → `times`
- `days` → количество выбранных дней

**Выполнено за неделю** — число дней с галочкой с понедельника по воскресенье.

**Запланирована ли привычка на день**
- `days` → день недели входит в `days`
- `weekly` → да, пока недельная цель не выполнена (или если в этот день уже стоит галочка)

**Серия (🔥)**
- `days` → сколько запланированных дней подряд выполнено, считая назад от сегодня
  (сегодняшний день не обнуляет серию, пока он не закончился)
- `weekly` → сколько недель подряд выполнена недельная цель

## 3. Экраны

### 3.1 «Сегодня»
1. Показать дату, стрелки ◀ ▶ для перехода по дням, кнопку «Сегодня».
2. Разделить привычки на две группы:
   - **По плану** — запланированы на этот день;
   - **Дополнительно** — не по плану (их тоже можно отметить).
3. Карточка привычки: большая кнопка-галочка, название, «Неделя: 2 из 3», серия 🔥, время напоминания ⏰.
4. Нажатие на галочку → поставить/снять отметку → сохранить → пересчитать прогресс.
5. Нажатие на название → открыть редактирование.

### 3.2 «Неделя»
1. Таблица: строки — привычки, столбцы — Пн…Вс, последний столбец — «сделано / план».
2. Запланированные дни отмечены рамкой, выполненные — галочкой.
3. Нажатие на ячейку → поставить/снять отметку.
4. Внизу — итог недели: сколько выполнено из запланированного всего.

### 3.3 «Календарь»
1. Выбор привычки (кнопки-чипы).
2. Сетка месяца, стрелки ◀ ▶ для смены месяца.
3. Выполненные дни закрашены, запланированные (режим `days`) — в рамке. Нажатие на день меняет отметку.
4. Статистика: выполнено за месяц, текущая серия, лучшая серия, всего выполнений.

### 3.4 Добавление / редактирование привычки
1. Ввести название.
2. Выбрать частоту:
   - «N раз в неделю» → выбрать N (1–7);
   - «По дням недели» → отметить дни.
3. Напоминание (по желанию): указать время, затем:
   - включить «Будильник со звуком»;
   - и/или нажать «Добавить в Google Calendar» / «Скачать .ics».
4. «Сохранить» → проверка (название не пустое, в режиме «по дням» выбран хотя бы один день) → запись.
5. «Удалить» → подтверждение → удаление привычки и её отметок.

### 3.5 «Статистика»
1. Переключатель «Неделя / Месяц», стрелки ◀ ▶ для перехода по периодам.
2. Для каждой привычки за период считается:
   - **План**
     - `days` → количество запланированных дней в периоде (не раньше даты создания привычки);
     - `weekly` → `times` × количество недель, чей **понедельник** попадает в период.
   - **Выполнено** — галочки в счёт плана (не больше плана). В режиме `days` отметки
     в незапланированные дни тоже засчитываются, если план ещё не закрыт.
   - **Пропущено**
     - `days` → прошедшие запланированные дни без галочки;
     - `weekly` → только по завершённым неделям: `план недели − сделано`.
   - **Осталось** = План − Выполнено − Пропущено (что ещё можно успеть до конца периода).
3. Показать:
   - три плитки: ✅ выполнено, ⏳ осталось, ❌ пропущено;
   - процент выполнения плана = Выполнено / План и полосу из трёх частей;
   - таблицу по привычкам: ✅ / ⏳ / ❌ / % и «сделано/план»;
   - график: столбики за 8 недель (процент выполнения плана по всем привычкам),
     последняя — неделя выбранного периода (но не позже текущей). Нажатие на столбик показывает цифры.

### 3.6 «Настройки» (кнопка ⚙ в правом верхнем углу)
- Разрешить уведомления.
- Проверить звук будильника.
- Экспорт данных в файл (резервная копия) и импорт из файла.
- Инструкция: как добавить приложение на экран «Домой».

## 4. Напоминания

### 4.1 Google Calendar
1. Пользователь нажимает «Добавить в Google Calendar».
2. Приложение формирует ссылку на Google Calendar с готовым событием:
   - название = название привычки;
   - начало = ближайший подходящий день, указанное время; длительность 15 минут;
   - повтор: режим `days` → каждую неделю в выбранные дни (`RRULE:FREQ=WEEKLY;BYDAY=MO,WE,FR`),
     режим `weekly` → каждый день (`RRULE:FREQ=DAILY`), потому что дни заранее неизвестны;
   - часовой пояс телефона.
3. Открывается Google Calendar → пользователь нажимает «Сохранить».
4. Дальше Google сам присылает уведомления, даже когда приложение закрыто.

Альтернатива — файл `.ics` (подходит для любого календаря, включая календарь iPhone);
в нём сразу задано напоминание точно во время события.

### 4.2 Будильник со звуком (работает, пока приложение открыто)
1. Каждые 10 секунд (и при возврате в приложение) проверить каждую привычку с включённым будильником:
   - текущее время ≥ времени напоминания и прошло не больше 30 минут;
   - сегодня ещё не звонил (`fired`);
   - привычка запланирована на сегодня и ещё не отмечена
     (для `weekly` — недельная цель ещё не выполнена).
2. Если всё выполнено → запомнить в `fired`, показать полноэкранное окно будильника,
   включить повторяющийся звуковой сигнал и вибрацию (если телефон поддерживает),
   а при разрешённых уведомлениях — показать системное уведомление.
3. Кнопки в окне будильника:
   - «Выполнено» → поставить галочку, выключить звук;
   - «Отложить на 10 минут» → выключить звук, повторить через 10 минут;
   - «Закрыть» → выключить звук.
4. Браузер разрешает звук только после касания экрана. Поэтому, пока звук не разблокирован,
   приложение показывает плашку «Коснитесь экрана, чтобы включить звук будильника».

---

## 5. Сохранение
Любое изменение (добавление, отметка, удаление) сразу записывается в localStorage.
При открытии приложение читает данные оттуда. Service worker сохраняет файлы приложения,
поэтому оно открывается и без интернета.
